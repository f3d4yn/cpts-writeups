# CPTS Writeups

Personal study notes and methodology writeups for the Hack The Box Academy
**CPTS (Certified Penetration Testing Specialist)** path.

## ⚠️ Publishing policy

This repo contains **educational notes and methodology only**:

- No literal exam content, exam flags, or exam answers — ever.
- Module skills-assessment answers/flags are **redacted**
  (`[REDACTED — see private note]`) — only the method to obtain them is shown.
- Only **retired** HTB machines are written up in full; active machines are
  never posted.
- Content is my own summary/rewording of concepts, not copied from HTB
  Academy material.

If you're studying for CPTS yourself, use this as a reference for
*technique* and *methodology*, not as an answer key.

## Structure

Each module gets its own directory with a `README.md` following the same
template: overview, key concepts, tools/techniques, mistakes made, and a
per-section methodology walkthrough.
